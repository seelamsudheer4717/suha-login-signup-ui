# Responsive Login and Sign-up UI

A responsive front-end project built with **HTML, CSS, and JavaScript**. It includes separate login and sign-up forms, inline validation, password visibility buttons, accessible tabs, and a mobile layout.

## Run locally

Open `index.html` in a browser. No installation or server is required. The Google Fonts import needs an internet connection; fallback fonts are included.

## What to try

1. Switch between **Log in** and **Sign up**.
2. Submit an empty form to see validation messages.
3. Enter a valid email and a password of at least 8 characters on the sign-up form.
4. Use **Show/Hide** to reveal or conceal the password.
5. Resize the browser to see the mobile design.

## Important scope

This is a **front-end UI demo**. It does not create accounts, authenticate users, email password resets, store passwords, or send form data to a server. A real login system requires a secure backend or authentication provider.

## Files

- `index.html` — accessible page structure and forms
- `styles.css` — responsive styling
- `script.js` — tabs, password toggle, and client-side validation
